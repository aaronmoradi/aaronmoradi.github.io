# aaronmoradi.com

My personal website, built by hand with plain HTML, CSS and JavaScript (no frameworks, no build step) and hosted on GitHub Pages.

## Pages

| Page | What it is |
| --- | --- |
| `index.html` | Home: hero with a live LA clock and a sky that follows LA time, about bento, projects, experience timeline, contact form |
| `map.html` | **Atlas**: an interactive life map (Leaflet + CARTO tiles) with a guided tour and a "how far am I?" button |
| `404.html` | Custom 404 with a playable basketball mini-game |
| `vault.html` | The secret easter-egg tracker |
| `about.html` | The forgotten page, preserved as a museum exhibit |
| `workout.html` | Private, PIN-locked |

## Code

- `css/styles.css`: shared design system (light/dark tokens, components)
- `js/main.js`: shared behavior: theme, nav, confetti, toasts, the terminal, and the easter egg registry
- `js/home.js`: home-page-only behavior
- `js/map.js`: the Atlas map
